# 💼 Fatma Dieye | Personal Portfolio

A responsive multi-page portfolio website built with **HTML5 and CSS3**, presenting my profile as a Computer Science student, my skills and my projects.

🔗 **Live site:** [fatmadieye.github.io/portfolio](https://fatmadieye.github.io/portfolio/)

## 📄 Pages

- **Home**: introduction and overview
- **About**: background, education timeline, technical skills and interests
- **Gallery**: selected projects (IoT, web, security, algorithms)
- **Contact**: how to reach me

## ✨ Features

- Responsive layout that adapts to phones, tablets and desktops (Flexbox and CSS Grid)
- Mobile navigation menu built with pure CSS, no JavaScript
- Custom design system with CSS variables (terracotta and sand color palette)
- Semantic HTML structure (`header`, `nav`, `main`, `section`, `footer`)
- Optimized images for fast loading

## 🛠️ Built with

- HTML5
- CSS3 (Flexbox, Grid, custom properties)
- [Google Fonts](https://fonts.google.com/) (Cormorant Garamond, DM Sans)
- Hosted on GitHub Pages

portfolio/

## 🚀 Run locally

```bash
git clone https://github.com/FatmaDieye/portfolio.git
```

Then open `index.html` in your browser. No installation needed.
